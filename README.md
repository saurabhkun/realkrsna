# RealKRSNA

> *Jab scene mein sab trend follow kar rahe the - Krishna Kaul bars likh raha tha.*

A fan-built website dedicated to **KR$NA (Krishna Kaul)** - one of the most technically gifted MCs desi hip-hop has ever produced. Built as a **frontend learning project** with zero frameworks, zero templates, zero shortcuts. Pure HTML, CSS, and vanilla JavaScript.

## ⚙️ Tech Stack

```
HTML            4 pages, fully interlinked, no framework
CSS             custom variables, grid, flexbox, scroll animations
JavaScript      vanilla only, zero libraries or dependencies
Spotify         embed player for all 15 tracks
GitHub Pages    free hosting
```

&nbsp;

## 🧠 What I Learned

- CSS `position: absolute` + `z-index` stacking for the collage homepage
- `IntersectionObserver` API for scroll fade-in animations on every section
- CSS custom properties for consistent theming across all pages
- `backdrop-filter: blur()` for the sticky frosted glass navbar
- Spotify embed iframe integration for the music player
- Git workflow - committing, pushing, GitHub Pages deployment
- Responsive design with `clamp()`, CSS Grid, and media queries
- Structuring a clean multi-page vanilla HTML/CSS/JS project
