About

001 - What is this

RealKRSNA

RealKRSNA is a fan-built site dedicated to Krishna Kaul - one of the most technically gifted MCs desi hip-hop has ever produced. This isn't an official page. No PR, no brand deals, no management. Just a fan who thinks KR$NA deserves more eyeballs.

This site is also a frontend learning project - built from scratch to get better at HTML, CSS, and JavaScript. No frameworks, no templates, no shortcuts. Every layout, every animation, every interaction written by hand. The music gave the motivation. The code gave the skill.

The design is intentional - all black, minimal, no noise. Because that's what the music sounds like. And because the best way to learn frontend is to actually have a vision and chase it, not just follow tutorials.

If you're a fan - this one's for you. If you're new to KR$NA - start with Makasam. You'll understand why this site exists.

002 - Features

What We Built

01
Built from Scratch
Zero frameworks. No React, no Tailwind, no Bootstrap. Pure HTML, CSS, and vanilla JavaScript. Every layout, hover effect, and animation is hand-written - because that's the only way to actually learn how it works.
02
Collage Homepage
8 image cards with overlapping positions and different aspect ratios - each linking to a different page. Hover to reveal the section title. Built using CSS absolute positioning and z-index stacking. No JS needed for the layout.
03
Music Player
Custom-built HTML audio player with progress bar, seek-on-click, prev/next, volume control, and auto-play on track end. No libraries. The player reads audio files served from the site - fully functional online.
04
Underrated Tracks Only
15 carefully picked tracks that most casual listeners sleep on. Not Roll Up, not Machayenge - the real deep cuts. From Sellout era (2014) all the way to Yours Truly (2025). If you know, you know.
05
Scroll Animations
Every section fades in as you scroll using the IntersectionObserver API - no jQuery, no GSAP. Sticky nav with blur backdrop, marquee text strips, and CSS transitions throughout. All written in about 20 lines of JS.
06
All Black. Minimal.
The design matches the music - raw, no clutter, nothing extra. Pure black backgrounds, off-white type, and Bebas Neue for display. A real design direction, not just a dark mode toggle. CSS variables keep everything consistent across all 4 pages.
